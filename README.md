# Proyecto 3 — Análisis de pingüinos de Palmer

## Descripción

Esta actividad consiste en un trabajo de análisis exploratorio (breve) en base a información acerca de pingüinos, específicamente en estudiar tres especies de pingüinos en la Antártida. En esta actividad no se aplica nada relacionado a machine learning, sin embargo, se lleva a cabo el uso de entornos virtuales, el aprender la manera de cómo clonar un repositorio y correrlo sin errores, lo cual beneficia al trabajo remoto entre compañeros e integrantes de un equipo.

## Dataset

* **Nombre:** Datos sobre pingüinos del archipiélago Palmer (Antártida) = (`penguins_lter.csv`)
* **Fuente:** Kaggle - Palmer Archipelago (Antarctica) Penguin Data
* **Descripción:** Base que contiene registros sobre medidas físicas como el tamaño y profundidad del pico (culmen), el largo de las aletas, la masa corporal, el sexo de los ejemplares y la isla donde fueron registrados.

## Objetivo

Explorar los datos para identificar patrones morfológicos entre las especies de los pingüinos, revisar si existe dimorfismo sexual en su peso y analizar cómo se distribuyen en las distintas islas del archipiélago, sin implementar modelos de Machine Learning.
